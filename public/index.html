Standard Callbridge Rules Reference

  • Objective: Be the player with the highest cumulative points after all rounds.
  • Bidding (Calls): Each player calls a minimum of 1 trick (up to 13).
  • Tricks Won: Total tricks across all 4 players MUST equal 13 every round.
  • Standard Scoring Formula:
    • If Won ≥ Call: Score = Call + (Won - Call) × 0.1
    • If Won < Call: Score = -Call
  • Example: Call 3, Won 4 → 3 + (4-3)×0.1 = 3.1 pts. Call 4, Won 3 → -4.0 pts.
